# Contributing

See README for the source installation and quality commands. Keep changes small,
typed, deterministic, offline at runtime, and supported by behavioral tests.
Never change tests to hide a defect. Avoid real user data in fixtures.

Follow ROADMAP and record decisions, evidence, defects, and next steps in STATE.
Phase boundaries require owner instruction. Target Windows/Linux and Python
3.12/3.13. The coverage gate is 90%; prioritize useful assertions over test count.
Do not claim hosted CI passed based on local execution.
